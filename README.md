# FetchFilm
Ce projet, réalisé dans le cadre du module 4.10, a pour objectif de concevoir un clone fonctionnel de l'interface Netflix en utilisant JavaScript (React).L'application permettra aux utilisateurs de parcourir les tendances actuelles, de naviguer par catégories de films et de consulter les détails des contenus. Ce développement vise principalement à valider la maîtrise de l'architecture front-end.

Les 3 couches à développer sont :

 - Frontend : Création de l'interface immersive reproduisant le design visuel de Netflix (bannière, carrousels défilants, lecteur vidéo).

 - Intégration API : Connexion à l'API externe pour récupérer et afficher les catalogues de films.

 - Backend : Mise en place d'une API REST pour gérer l'inscription, l'authentification des utilisateurs et la sauvegarde de leurs favoris.

La page d'accueil sera composé de plusieurs éléments : 

 - La bannière : Une section principale immersive affichant le film "à la une" avec une image de fond, le petit résumé qui va avec.

 - Rails de contenu : Des carrousels avec les films par catégories.

 - Barre de Navigation : Un menu supérieur avec le logo
